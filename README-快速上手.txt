wkfile · 快速上手
========================================

现在只需要一个 exe：wkfile.exe，放在【Windows 服务器】上。
跑 AI 客户端（Trae / Cursor / Claude Desktop 等）的那台电脑【不用装任何东西】，
在客户端里配一行 JSON 就能用。

【服务器这边到底要不要装 Python？】
  用 wkfile.exe（推荐）→ 不用装。Python 解释器已经打进 exe 内部了，
                          拷过去双击就能跑。
  用源码 .py 版        → 要装 Python 3.8+（python.org 官方安装包，自带 tkinter）。
  两种情况都【不需要 pip install】—— 本项目零第三方依赖，全部是 Python
  标准库；也不需要 openssl（自签证书是程序自己算出来的）。
  系统前提：Windows 10 / Server 2016 及以上（自带运行库）。

（1.4.0 起包里只有 wkfile.exe 这一个程序：隧道和「本地桥接」两种旧接入方式
  已从程序里彻底移除，只剩 IP 直连一条路。
  1.5.0 补了几道安全闸；1.5.1 起所有运行时数据收进一个 wkfile\ 文件夹；
  1.6.0 又补上 HTTPS、一键自签证书、只读 Token、备份回滚、日志轮转与几个排障工具；
  1.6.0 起 MCP 配置里会自动填好本机公网 IP，不再只给内网地址，
  证书也能填 public + chain + key 三件套（程序自动合并成 fullchain）。
  1.6.1 修了两个数据库连接超时的问题：多地址（IPv6 黑洞那种）不再把
  超时预算叠着用，配置里的秒数填错也不会再报"内部错误"；
  界面④多了「连接超时」这一个框。
  1.6.2 起：配置文件不存在时会自动生成一份带中文注释的模板（数据库那段
  可照抄），并新增「关于」页显示作者信息；
  1.6.3 定稿：作者 吴康，微信 wukang —— 界面「⑤ 关于」页 + 窗口底部独立一行。
  1.6.4 修了「④ 数据库」页不能滚动的问题，并把白名单的安全边界写进了 README；
  1.7.0 新增 SQL Server（SQSRV）数据源：纯标准库 TDS 协议实现（全程 TLS 加密、
  SQL 身份验证），界面④多了【＋ SQL Server】按钮，默认端口 1433。）

程序运行时【只创建 wkfile 这一个文件夹】，里面装着配置、日志、备份、回收站；
不会往你允许 AI 操作的业务目录里撒任何东西。

首次运行如果 Windows 提示「未知发布者 / 已保护你的电脑」，点
【更多信息】→【仍要运行】即可（没买代码签名证书，不是病毒）。
若被「智能应用控制」直接拦死且没有「仍要运行」按钮，那台机器请改用
源码版（启动界面.bat + Python）。


----------------------------------------
端口：记住 10087
----------------------------------------
这就是你服务器上实际在用的端口，客户端填它。
程序内置默认值是 8788，只是模板值；界面上填多少就以多少为准。
另外：别去连 22 端口 —— 那跟本工具无关，连它必然超时。


----------------------------------------
一、服务器上（3 步）
----------------------------------------

1. 把整个文件夹放到例如 D:\wkfile-server\ 目录
   （别放 C:\Program Files，那里写数据会被系统重定向；
     真放了也不怕，程序会自动退到 C:\ProgramData\wkfile\）

2. 双击【以管理员身份启动.bat】（或右键 wkfile.exe → 以管理员身份运行），
   然后按三个页签配置：

   （首次双击可能卡十几秒到一分钟 —— Windows Defender 在扫描这个新出现的
     未签名程序，属正常现象，之后就快了。
     程序里每次操作的结果都会显示在窗口顶部的浅色状态条上：绿=成功 黄=提醒 红=失败。
     点了按钮没看到变化，就看那条状态条。
     窗口底部始终有「运行日志」区；页签内容放不下时是页签内部滚动，不会盖住日志。）

   ① 基础设置
      - 监听地址：客户端在另一台电脑上 → 选 0.0.0.0
      - 端口：填 10087
      - 点【添加目录…】把允许 AI 读写的目录加进来（可加多个）
        注意：别图省事把整个 D:\ 或 C:\ 加进去；系统目录【永远不要】加。
        越窄越安全 —— 这个服务对白名单目录是有删除和移动权限的。

   ② 安全与权限
      - 点【生成】得到一个 Token（相当于访问密码，别外传）
      - 有效期：默认「永久」。想更稳妥可以填 7 / 30 / 90 天（或任意天数），
        到期那一刻起服务会拒绝所有请求（客户端会突然连不上）——
        所以请在到期前点一次【生成】，或点【按此重新计时】续期。
        下方会实时显示「还有多少天到期」，不足 3 天会变橙色提醒。
      - 来源 IP：每行一条，例如
            192.168.1.*
            10.0.0.0/8
            203.0.113.45
        留空 = 不限制来源（公网服务器强烈建议填上你办公网的出口 IP）
      - 按需勾选：只读模式 / 允许删除（删进回收站）/ 允许移动 /
        覆盖前自动备份 / 写入前语法校验
        只是想让 AI 看代码 → 勾只读，或至少把「允许删除」「允许移动」关掉
      - 「开放 MCP 端点」保持勾选 —— 客户端直连就靠它
      - 下半部分【工具级开关】可以逐个关掉不想让 AI 用的工具；
        想"只查看"直接点【只留只读】，最省事

   ③ 安装与运行
      - 【保存配置】→【启动服务】（顶部状态变成「● 正在运行」）
      - 【安装开机自启】开机自动运行，不需要登录（需管理员）
      - 【放行当前端口】写防火墙规则（需管理员）
        云服务器还要去控制台安全组放行同一端口，否则白放
      - 底部的「其它」里能设【审计日志轮转】（默认超 5 MB 滚动、留 3 份）
        和【清空审计日志】

   ③ 页下半部分「MCP 客户端配置」（Trae / Cursor / Claude Desktop 等）：
      - 「服务器地址」程序会自动填好：启动时探测本机公网 IP 写进去
        （客户端在另一个网络时，内网 IP 一定连不上）。
        同一局域网用内网 IP 更快，或探测失败时可以点【检测公网 IP】重试、
        也可以直接手改这一栏。
      - 点【复制 MCP 配置】—— 剪贴板里就是填好地址和 Token 的 JSON，直接粘给客户端

   ④ 数据库（可选，不用就整页留空）
      - 这一页是给"除了文件，还想让 AI 一起看数据库"的场景准备的。
        默认一个数据源都不填，等于这个能力完全关闭，不影响别的功能。
      - 点【＋ MySQL】【＋ SQL Server】或【＋ Redis】加一条，填好主机 / 端口 / 账号 / 密码
        （MySQL / SQL Server 再填库名，Redis 填 0-15 的库号；
         SQL Server 仅支持 sa 这类 SQL 账号，不支持 Windows 集成认证，
         连接全程加密，服务器默认证书即可）
      - 点【测试连接】当场验一次：通了会显示服务端版本和能看到几个库；
        不通会直接说清是网络、认证还是权限问题
      - 两个超时别混：
          「连接超时」= 拨号预算（域名解析 + 建立 TCP 连接），默认 8 秒；
          「查询超时」= 连上之后等结果的时间，默认 MySQL / SQL Server 30 秒 / Redis 15 秒。
        库在公网或跨地域、建连慢，就把「连接超时」调大；
        想让卡住的查询快点失败，就调小「查询超时」。
        填 0、负数或乱码不会让程序崩，会自动退回默认值（上限 300 秒）。
      - 【允许写入】默认不勾 = 只能查询。要放开写操作，除了勾它，
        还得保证服务端不是只读模式、客户端用的是主 Token（三个条件都要满足）
      - 最后点【保存配置】并重启服务才生效
      - 危险动作永远被拒，跟上面这些开关无关：多语句、INTO OUTFILE、
        LOAD_FILE、FOR UPDATE，以及 Redis 的 FLUSHALL / CONFIG / EVAL / KEYS
      - 建议：给这个服务单独建一个只读的数据库账号，不要直接填 root。
        密码是明文存在配置文件里的（服务器上能登进来的人看得到）。
      - 不想用界面？也可以直接改配置文件（见下面「数据库配置到底在哪儿」）

   ⑤ 关于（作者信息）
      - 作者：吴康    微信：wukang
        有【复制】按钮一键复制微信号。
      - 纯展示页，没有任何联网行为，也不影响任何功能。

   数据库配置到底在哪儿？（两种改法，效果完全一样）
      ① 图形界面：「④ 数据库」页点两下 —— 推荐，第一次配就用这个。
      ② 直接改文件：记事本打开 wkfile\wkfile.config.json，
         找到 "databases": [] 这一段，照着紧跟在后面的注释示例抄一份。
         改完保存、重启服务即可，其它项不用重新配。

   那个配置文件是程序自动生成的 —— 第一次运行就会在 exe 旁边建好
   wkfile\wkfile.config.json，里面自带中文注释和可照抄的数据库示例。
   注释用 // 开头，程序读的时候会自动跳过，不会把 JSON 弄坏。

   所有东西都在这一个文件夹里（就在 exe 旁边）：

      wkfile\wkfile.config.json      配置（含 Token）
      wkfile\wkfile.pid              服务进程号
      wkfile\logs\wkfile.log         运行日志
      wkfile\logs\audit.jsonl        审计日志（每次操作都有记录）
      wkfile\backups\                改写文件前的自动备份
      wkfile\trash\                  删掉的东西（可恢复）

3. 完事。不用再配别的东西。


----------------------------------------
二、客户端那台电脑上（只需 1 步）
----------------------------------------

把服务器界面里复制的 JSON 粘进客户端：

   以 Trae 为例：设置 → MCP → 添加 → 手动配置 → 原始配置 → 粘贴 → 保存
   Cursor：设置 → MCP → Add new MCP server
   Claude Desktop：设置 → 编辑配置（claude_desktop_config.json）
   字段含义三家完全一样，都是下面这一段。

内容长这样（地址和 Token 已替你填好，下面是示例）：

{
  "mcpServers": {
    "wkfile": {
      "type": "http",
      "url": "http://1.2.3.4:10087/mcp",
      "headers": { "Authorization": "Bearer 你的Token" }
    }
  }
}

也可以把这段写进【项目根目录】的 .trae\mcp.json（Cursor 是 .cursor\mcp.json），
效果一样（只对该项目生效）。
注意是"客户端打开的那个工作区根目录"，不是随便哪个子目录。

如果你的客户端只认 SSE，把 type 改成 "sse"、url 末尾的 /mcp 换成 /sse。

配好后客户端的 MCP 列表里 wkfile 会显示 Running，工具列表里能看到 33 个
win_* 工具（win_ 前缀表示"Windows 上的操作"，与产品名无关；
其中 23 个是文件类、10 个是数据库/缓存类）。
然后就可以在对话框里直接说：

    「先 win_roots 看看能操作哪些目录」
    「看看 E:\apps 下面有哪些文件」
    「把 E:\apps\config\database.php 里的 db.host 改成 10.0.0.5」
    「在 E:\apps\logs\app.log 里搜一下 Error」


----------------------------------------
三、连不上怎么办
----------------------------------------

服务器上双击【连接自检.bat】（或跑 connect-check.py），
它会一次性告诉你：配置对不对、服务在没在跑、内网有哪些地址、公网 IP 是多少、
防火墙放行没、以及可以直接粘贴的客户端配置（默认优先给公网 IP）。

手边有 Python 的话，从任意机器也能测：

    python tools\probe-public.py 1.2.3.4
    python tools\mcp-public-test.py http://1.2.3.4:10087 你的Token
    python tools\mcp-call-test.py  http://1.2.3.4:10087 你的Token win_roots

症状对照：
  /mcp 返回 401      → Token 不对（或少了 "Bearer " 前缀）
  /mcp 返回 404      → MCP 端点被关了，回界面勾上「开放 MCP 端点」
  Connection timed out → 端口/防火墙/云安全组/IP 错
  out_of_scope       → 路径不在白名单目录里，这是正常的越权拦截
  ambiguous_match    → win_replace 的 old 在文件里出现多次，让它补上下文或指定 count
  preflight_failed   → 要写入的 .py/.json/.xml/.toml 语法不对，服务端拦下且原文件没动


----------------------------------------
四、安全提醒（请务必读）
----------------------------------------

这是能读写服务器真实文件的接口，而且现在是公网暴露、只靠一道 Token：

  * Token 一旦在聊天记录/截图里出现过，立刻点【生成】换新的，并同步更新客户端
  * 云服务器：安全组里把端口来源限制成你自己的出口 IP，不要 0.0.0.0/0
  * 「限制目录」收窄到真正要改的子目录；生产项目里的 config/、
    test_db_connect.php 这类存数据库凭据的文件尤其要留意
  * 只想让它看、不让它改：勾上【只读模式】，或填一个【只读 Token】
  * 上 HTTPS：界面③勾上「HTTPS」，没域名就点【生成自签证书】现场签一张，
    Token 就不用明文过公网了（详见 README.md 第 7 节第 7 条）  * 一切写入都有备份（wkfile\backups\），删除都进回收站（wkfile\trash\），可恢复
  * 越权访问会被直接拒绝（返回 out_of_scope），白名单外一个字节都碰不到
  * 连 wkfile 自己的数据目录也是拒绝访问的 —— 配置里有 Token，
    不能让它被 AI 读走


----------------------------------------
五、卸载
----------------------------------------

  1. 打开 wkfile.exe：先【停止服务】，再【卸载开机自启】和【关闭放行】
  2. 删除整个文件夹即可（配置和日志都在里面的 wkfile\ 下）
  3. 客户端侧把 MCP 配置里的 wkfile 项删掉


----------------------------------------
六、安全闸一览（不用你配置，自动生效）
----------------------------------------

  * 启动前拒绝裸奔：如果监听地址不是本机、而 Token 是空的或还是示例里那句
    占位文字，程序会【拒绝启动】并告诉你怎么办。想强行启动只能显式加
    --allow-unsafe（不建议）。
  * 监听非本机 + 允许删除/移动时，点【启动服务】会弹一次高风险确认。
  * 写入前语法校验：.py / .json / .jsonl / .xml / .toml 先验语法，
    不通过就一个字都不写（原文件完全不动）。想故意写半截配置可以关掉它。
  * win_replace 保护：要替换的片段在文件里出现多次、而调用方又没明确说
    "替换几处"时，这次调用会被拒绝，避免一次改错多处。
  * 审计日志与运行日志都会自动轮转（审计超 5 MB、运行日志超 2 MB 滚动，
    各留 3 份），不会无限增长把磁盘写满。
  * /health 只回服务名和版本，不再暴露主机名、Python 版本、目录数量；
    想看详情要带 Token 访问根路径。
  * 33 个工具都带上了 MCP 标准风险标注，客户端才能正确区分
    "只读" 和 "会改东西"，安全提示不再失真。
  * 数据库工具默认是关的（数据源列表为空 = 能力关闭）。开了之后：
    写操作要同时满足"数据源允许写入 + 服务端非只读 + 用主 Token"三条；
    危险语句（多语句、INTO OUTFILE、LOAD_FILE、FLUSHALL、CONFIG、EVAL、
    KEYS…）无论怎么配都不放行；密码不会经任何接口回传。
  * 数据目录隔离：配置/日志/备份/回收站全部收进 wkfile\，
    既不污染业务目录，也不能被接口读到。
  * Token 有效期：可设成 N 天后自动失效（默认永久）。到期后所有请求返回
    401 token_expired，服务端启动横幅也会醒目提示。命令行续期：

        python wkfile_agent.py --renew-token --token-days 30

  * 只读 Token：界面②可以再生成一个"只读 Token"。拿它连进来的客户端
    只能看，写/删/移/回滚一律被拒。适合"只想让 AI 读代码"的场景，
    而且不影响主 Token 的权限。
  * 自带 HTTPS + 一键自签证书：界面③勾上「HTTPS」，有域名就选正式证书；
    没域名就点【生成自签证书】—— 程序现场签一张，纯本地运算，
    不装 openssl、不装任何包、不联网，约 1-2 秒完成。
    它会把 127.0.0.1 + 本机内网 IP + 探测到的公网 IP 全写进证书 SAN
    （少写一个，客户端按那个 IP 连就必然校验失败），生成完自动填好路径、
    自动勾上 HTTPS、自动检查一遍。配完把客户端里的地址改成 https:// 即可。
    命令行也能生成（**源码版**专用，适合没有桌面的服务器）：

        python wkfile_agent.py --gen-selfcert

    （图形版 wkfile.exe 不接这些命令行参数 —— 它是 windowed 编译的、没有控制台，
      执行了你也看不到结果，所以给 exe 加这些参数时会弹窗提示你改点界面按钮。）

  * 界面③的 HTTPS 那一栏有三个框，对着证书商给你的文件填就行：
        ┌──────────────┬──────────────────────────────────────────┐
        │ 证书商给几份  │ 怎么填                                    │
        ├──────────────┼──────────────────────────────────────────┤
        │ 只有 IP       │ 点【生成自签证书】，三个框都不用管          │
        │ crt + key     │ 第一行填 crt、第三行填 key，中间链留空      │
        │ public +      │ 三份依次填进三个框（公钥证书 / 中间证书链 /  │
        │ chain + key   │ 私钥），程序启动时自动把前两份并成一份       │
        │ 一份 fullchain│ 第一行填它，中间链留空                     │
        └──────────────┴──────────────────────────────────────────┘
    三件套合并出来的文件在 wkfile\tls\fullchain.pem，可以打开核对。

  * 最容易踩的坑：证书链不完整
      证书商后台通常同时给「单张 crt」和「带链的 chain/fullchain」两种文件，
      选错了当场看不出来：浏览器和 Windows 会自己顺着证书里的 AIA 地址把中间
      证书补回来，所以浏览器里访问一切正常；但 Trae / Cursor / Claude Desktop
      这类 Electron 客户端走 Node 的 TLS 栈、不补链，会直接报
      unable to verify the first certificate 而连不上 —— 表现就是
      「浏览器能开、客户端连不上」。
      程序对这种情况有三重提醒，不用你自己猜：
        ① 界面点【检查证书】会当场标黄提示「只有 1 张证书，没带中间证书」；
        ② 服务启动横幅会打 [!] 证书文件里只有 1 张证书，没带中间证书；
        ③ 服务器上跑【连接自检.bat】会直接判红并给出两种改法。
      改法：第一行换成 fullchain，或者把链文件填进「中间证书链」那一栏。
  * 备份可回滚：AI 改坏了文件，可以用 win_backup_list 看历史版本、
    用 win_backup_restore 回滚。回滚前还会先把当前版本再存一份，
    所以回滚本身也能撤销。
  * 排障更省事：win_tail 直接看日志末尾、win_tree 一眼看目录树、
    win_multi_read 一次读多个文件、win_replace 加 dry_run=true
    可以先看 unified diff 预览再决定要不要改。
  * 所有 MCP 工具调用都写进审计日志（以前只记裸 HTTP 接口）。
  * MCP 配置自动填公网 IP：以前「服务器地址」默认填的是内网 IP，
    客户端在另一台机器上根本连不到。现在程序启动时会探测本机公网 IP
    并自动填进这一栏（探不到就保持内网 IP，不影响任何功能），
    也可以随时点【检测公网 IP】重探。内网互通时手改回内网 IP 即可。
