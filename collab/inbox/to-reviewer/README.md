# to-reviewer（workbuddy → reviewer）

这里是 **workbuddy 投给 reviewer** 的收件箱。

- 只允许 workbuddy 写入；reviewer 只读、验收、改状态。
- 文件名：`MSG-<TASK-ID>-<NNN>.md`，序号接在请求消息之后。
- 交付必须使用 `type: delivery`，并满足 `protocol.md` 第 9 节的六项内容。
- 验收完成后移动到 `../../archive/<TASK-ID>/`。
- 详细规则见 [../../protocol.md](../../protocol.md)。
